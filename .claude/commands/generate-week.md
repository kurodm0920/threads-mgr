# /generate-week

週次一括生成コマンド。1コマンドで **翌週月〜日 = 21投稿** を生成・予約する（2026-05-27 改訂で 35→21 本に削減、18:00 廃止、平日深夜23:15新設、金土日半減）。

起動推奨タイミング: **日曜の夜（22:00〜）**。次の月曜0:00 JST 以降に始まる7日分を生成。

## 実行手順

### 1. 環境変数読み込み

```bash
source <(grep -v '^#' .env.local | sed 's/^/export /')
```

### 2. 過去2週間のデータ取得

ローカル dev のポートは可変（3000/3001/3002 のいずれか）。実際の port は `lsof -nP -iTCP -sTCP:LISTEN | grep node` で確認。

```bash
curl -k -s -H "Authorization: Bearer $CC_API_KEY" \
  "https://localhost:3002/api/cc/inspirations-export?days=14" \
  > /tmp/cc-export-week.json
```

ローカル dev が動いてない場合は本番URLで取得:

```bash
curl -s -H "Authorization: Bearer $CC_API_KEY" \
  "https://threads-mgr.vercel.app/api/cc/inspirations-export?days=14" \
  > /tmp/cc-export-week.json
```

このJSONには:
- `published_posts`: 過去投稿
- `post_metrics`: 各投稿の数値（views/likes/replies/reposts/quotes）
- `post_features`: 抽出済み特徴
- `inspirations`: 業界バズ投稿（手動 + keyword_trend）
- `recent_knowledge`: 最新ナレッジサマリー

### 3. 分析

`/tmp/cc-export-week.json` を読み込み、以下を抽出:
- **winners**: 上位30%（views）の投稿を直近2週間から抜き出し、冒頭フックを分類
- **losers**: 下位25%（0-3views）を回避パターンとして記録
- **inspirations の傾向**: 文字数中央値、絵文字数、冒頭パターン
- **時節**: CLAUDE.md の「天体イベント連動カレンダー」を参照、来週分のイベントを抽出

### 4. 週間スロット計算（21本、曜日別）

起動日（通常は日曜夜）の翌日0:00 JST から始まる7日 × 曜日別本数 = 21スロットを計算。

| 曜日 | 本数 | スロット (JST) |
|---|---|---|
| 月 | 3 | 07:30 / 12:15 / 21:30 |
| 火 | 4 | 07:30 / 12:15 / 21:30 / 23:15 |
| 水 | 4 | 07:30 / 13:30 / 21:30 / 23:15 |
| 木 | 4 | 07:30 / 14:00 / 21:30 / 23:15 |
| 金 | 2 | 12:15 / 21:30 |
| 土 | 2 | 12:15 / 21:30 |
| 日 | 2 | 12:15 / 21:30 |

JST → UTC は -9時間（前日 23:45 = 当日 14:45 UTC など）。

### 5. 21投稿の配分

**ジャンル配分**（週合計21本）:
- 西洋占星術 **60% → 13本**
- 紫微斗数 **25% → 5本**
- 四柱推命 **15% → 3本**
- 易経 **0%（停止中）**

**コンテンツタイプ配分**:
- 共感系 **65% → 14本**
- 今日の運勢 **15% → 3本**
- 豆知識系 **10% → 2本**
- ストーリー型 **0%（廃止）**
- CTA投稿 **10% → 2本（セット運用）**

**画像つき投稿**:
- 21投稿中 **4〜5投稿** を画像つきに（バズ投稿の60%が画像有のため）
- 画像プール（`public/buzz-images/`、計5枚）からテーマ整合の1枚を選定:
  - `moon-ocean.png` — 海上の満月（テーマ: moon、夜の共感系）
  - `shrine-morning-light.png` — 朝光の神社（テーマ: shrine、開運・朝投稿）
  - `torii-sunset.png` — 海の鳥居と夕焼け（テーマ: shrine）
  - `golden-buddha.png` — 金の仏像（テーマ: sacred、命式系）
  - `dragon-cloud.png` — 龍雲（テーマ: sky、天体イベント系）
- URL 形式: `https://threads-mgr.vercel.app/buzz-images/<filename>`
- `media_urls: ["<URL>"]` として登録

### 6. CTA セット運用（必須・2026-05-27 追加）

CTA単体は平均6views（通常21.5の1/3）で死ぬため、必ず「**直前 winner empathy → 次スロットで CTA**」のセットにする。

週2セット例:
- **セットA**: 火 23:15 winner empathy → 水 12:15 CTA
- **セットB**: 木 14:00 winner empathy → 木 21:30 CTA

CTA本文では「前の投稿で書いた◯◯について、詳しく知りたい方へ」のように、直前 empathy 投稿との文脈接続を明示する。

### 7. 冒頭フック必須化（2026-05-27 追加・最重要）

**全21投稿の冒頭1〜2行で「読者を絞り込むフレーズ」を必ず入れる**。winner TOP4 全部このパターンだったため。

テンプレ:
- 「◯◯の夜、◯◯な方にだけ起こる現象があります」
- 「火曜の深夜にこの投稿を見ている方、ある共通点があります」
- 「四柱推命で◯◯を持つ女性に共通する傾向があります」
- 「◯月◯日、◯◯な方ほど運が動きます」

一般論NG例:
- ❌「双子座の太陽は言葉を運びます」← 誰にも刺さらない
- ❌「今日の運勢をお伝えします」← セグメントなし

セグメント呼び込み OK例:
- ✅「双子座入りの前夜、眠れない方にだけ起こる現象があります」
- ✅「火曜の深夜にこの投稿を見ている方、ある共通点があります」

### 8. 天体イベント連動（必須）

CLAUDE.md の「天体イベント連動カレンダー」を参照し、来週分のイベントに合わせて winner empathy を仕込む。

主要イベント（2026年）:
- 6/6 双子座新月、6/9 水星双子座入り、6/21 夏至・蟹座シーズン、7/3 山羊座満月、7/14 水星逆行、8/8 ライオンズゲート

イベント当日 or 前夜 23:15 のスロットに「イベント絡みの winner empathy」を必ず1本配置。

連投制限: 同じイベント絡みのフックは **3日以内に連続2本まで**。

### 9. 専門用語のルール

**SNS集客は読みやすさ最優先**:
- **1投稿に専門用語は1個まで**、必ず平易な言い換えとセット
- 避ける用語: 食神/印綬/偏官/正官/偏財/正財/比肩/劫財/傷官/偏印（四柱推命）/太陰星/破軍/天府/天梁/紫微（紫微斗数）/離為火/坤為地/震為雷/水沢節/卦（易経）
- 使える一般語: 星座名（双子座/牡牛座等）/命式/運気/縁
- 詳細は CLAUDE.md「専門用語のルール」参照

### 10. CTA本文のルール

- **外部URL直貼り禁止**（凍結リスク）
- LINE 誘導は「**プロフィールから**」のプロフ遡求型のみ
- 例: 「プロフィールのリンクから LINE にお越しください」「詳しくはプロフィールへ」
- `cta_target_url` は **null** のまま、`has_cta=true` だけ立てる

### 11. フォローCTA（empathy系 5本に必須）

empathy 系 12本のうち、**5本の末尾に「開運フック型フォローCTA」**を追加。CLAUDE.md「フォローCTA運用ルール」参照。

**割り当て指針**:
- 朝7:30 / 12:15 の運勢系・tips系・CTA投稿には**入れない**
- 夜（21:30 / 23:15）の empathy に集中
- 5パターンをローテーション（連続使用NG）

**例**:
- 月 21:30 新月前夜の種撒き empathy → ⑤新月パターン
- 火 23:15 深夜の前夜組 empathy → ①深夜パターン
- 木 23:15 気だるさ empathy → ④夜の縁パターン
- 土 21:30 一週間の疲れ empathy → ③月の流れパターン
- 日 21:30 月初の予感 empathy → ②シーズンパターン

文体厳守:
- ✅「私はこういう方を何人も視てきました」「視てきた中で〜」← 権威性
- ✅「フォローしておいてください」「続きをここで書いていきます」← 口語
- ❌「いただければ」「お届けします」← よそよそしい

### 12. コメント誘導 CTA（任意）

明示 CTA 2本とは別に、3〜4投稿の末尾に「コメントください」系の柔らかい問いかけを入れる:
- 例: 「あなたの星座はどれですか？コメントで教えてください」「気になる方はコメントで一言だけ」
- 目的: インプレッション増、エンゲージメント率底上げ
- 押しつけない柔らかさで、全投稿にはやらない

### 13. バリエーション保証

- 同じ書き出しパターンが3日連続にならない
- 同じジャンル × 同じスロットが連続しない
- 「セグメント呼び込み」のテンプレも3種類以上をローテーション

### 14. 生成

文体・文字数:
- 文体: ですます調、絵文字なし、占い系の落ち着いた語り、末尾に「志麻」など署名入れない
- 文字数: 150〜250字（過去 winners の中心帯）。300字超えはイベント絡みの大型 empathy のみ
- 禁止語: 「絶対」「100%」「必ず」「確実」など断定表現

### 15. プレビュー（3段階表示）

**Step 1: 週間サマリー**:

```
週間サマリー（6/1 月〜 6/7 日、計21本）
─────────────────────────────────
ジャンル配分: 西洋13 / 紫微5 / 四柱3 / 易経0
タイプ配分:   共感14 / 運勢3 / 豆知識2 / CTA2

CTAセット:
  セットA: 火 23:15 winner → 水 12:15 CTA
  セットB: 木 14:00 winner → 木 21:30 CTA

天体イベント連動:
  6/6 双子座新月 → 前夜 6/5 23:15 + 当日 6/6 12:15 に配置

各日のテーマ:
  月 6/1: 月始まり・週の始まり共感（3本）
  火 6/2: 双子座シーズン中盤・深夜共感（4本）
  水 6/3: 新月3日前の仕込み（4本）
  ...
```

**Step 2: 日ごとの全文プレビュー**:

```
=== 火 6/2 (4本) ===
[07:30 astrology/empathy] "..."（180字）
[12:15 shibun/empathy   ] "..."（210字）
[21:30 astrology/empathy] "..."（200字）
[23:15 astrology/empathy] "..."（230字）← winner empathy
```

**Step 3: ユーザー操作**

- 全体OK → 「OK」「予約して」→ Step 15 で一括 INSERT
- 個別修正 → ピンポイント差し替え
- 全体やり直し → 全体再生成

### 16. POST /api/cc/posts-bulk（21件一括）

ローカル dev のポートを正確に指定:

```bash
curl -k -X POST \
  -H "Authorization: Bearer $CC_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"posts": [/* 21件の配列 */]}' \
  https://localhost:3002/api/cc/posts-bulk
```

### 17. 結果報告

投入された投稿のID・時刻リストをユーザーに報告し、以下を案内:

```
✅ 21投稿の予約完了。
   - 最初: 月 6/1 7:30 JST
   - 最後: 日 6/7 21:30 JST

ダッシュボードの /calendar で予定一覧が見られます。
個別修正は /drafts ページから可能です。

次回 /weekly-review は 6/8 月曜の朝以降に実行推奨。
```

## 注意

- 突発トレンドには追従できない → `/drafts` で個別差し替え
- 21本は少ないので、1本あたりの密度・フック強度を最大化する
- セグメント呼び込みフックを全21本に徹底
- 占術倫理（断定表現NG）を厳守
